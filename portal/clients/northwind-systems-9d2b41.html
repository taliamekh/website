Benchtop Test & DAQ Rig

A reconfigurable benchtop rig that drives a small-motor endurance test and logs torque, temperature, and vibration to a single synchronised data set for pass/fail analysis.

Overview

Northwind is qualifying a new gearmotor and needs repeatable, instrumented endurance runs instead of hand-timed bench tests. The rig applies a programmable load profile, holds setpoints, and writes every channel to one time-aligned log so a run is trivially comparable to the next.

This is the scoping plan — we agree the requirements and architecture here, then I build the fixture, wire the DAQ, and hand over a documented rig your team can run unattended.

Scope

✓ In scope

  • Programmable load (magnetic-particle brake)
  • Torque + speed sensing on the output shaft
  • 3× thermocouples + 1× MEMS accelerometer
  • Synced logging to CSV at 1 kHz
  • Setpoint control + auto-stop on fault
  • Quick-swap motor mounting plate

— Out of scope (for now)

  • Climate / humidity chamber integration
  • Automated report generation
  • Production-line / multi-station version
  • Custom analysis dashboard
